# CryptoBigot2 — Demo Exchange

CryptoBigot2 is a static, browser-based cryptocurrency exchange interface for learning and demonstration.

## Open the website

- Live GitHub Pages site: https://dawitmengist263.github.io/cryptobigot2/
- Main dashboard: open the live site above.
- Standalone demo login: https://dawitmengist263.github.io/cryptobigot2/login.html
- Support prototype: https://dawitmengist263.github.io/cryptobigot2/support.html
- Admin sandbox prototype: https://dawitmengist263.github.io/cryptobigot2/admin.html

## Important limitations

- Orders and balances are simulated; no real trades, deposits, or withdrawals occur.
- Some market information uses Binance's public market-data API and may be unavailable depending on network or regional access.
- Profile settings, watchlists, support messages, and admin sandbox records are stored only in the current browser.
- GitHub Pages hosts static files; it does not provide a secure database, server-side authentication, or private admin access. Do not enter real passwords, wallet seed phrases, private keys, or sensitive financial information.

## Deployment

GitHub Pages is configured to publish the root of the `main` branch. After changes are merged into `main`, allow a short time for Pages to rebuild, then refresh the live site. If the old version remains, use a hard refresh (Ctrl+F5 on Windows).
